# last-done-tracker

「最後にいつやったか」をiPhoneに記録する、サーバー・データベース不要のシンプルなWebアプリです。

## 機能

- 記録したい項目の追加
- 「今やった」ボタンによる最終日時の更新
- 経過時間が長い順で表示
- 項目名の編集と削除
- JSONバックアップの書き出し・復元
- データはブラウザのローカルストレージだけに保存

## GitHub Pages

リポジトリの `Settings` → `Pages` を開き、`Deploy from a branch`、`main`、`/(root)` を選択します。
